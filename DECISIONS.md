# Implementation decisions

1. This is an original procedural-art prototype. Reference screenshots guide composition and the cutaway view; no imagery is copied. One 64×64-tile room is positioned inside the central 2×2 chunks of a 4096 px world, with a neutral floor beyond it.
2. Character base, garment, headwear and prop sheets use actual Aseprite JSON-array files from the beginning. The importer restores trimmed frames to a full canvas before mirroring/compositing. The Lab and build share the same pure typed-array compositor; adapters only move the resulting pixels into canvas or sharp.
3. A 60-frame action map distributes each action's unique frames over the character loop. Holds are implicit equal-length intervals. Prayer uses eight art frames for four posture pairs and is explicitly flagged for panel review.
4. Content is seeded only when absent. Existing part sheets are preserved on subsequent generator runs. The PRNG is build-time-only, with seed 796. The optional worshipper variant has its own serialized seed and resolves before validation. Runtime simulation contains no PRNG or wall-clock reads.
5. A later person's exact full-name exception does not exempt another occurrence of the same given name. Lineage tokens are excluded after the first ibn/bin/bint separator; exact full identities and given-name tokens are checked. Umar ibn Abd al-Aziz and Fatima al-Fihri are intentionally allowed. No panel approvals are fabricated.
6. All sample named cards remain unapproved and unresearched. Consequently `pnpm build` must fail. `pnpm build:preview` is explicitly a draft review artifact; it is not an approved release.
7. Camera URL x/y values describe the world centre, not screen offsets. The shared `screenToWorld` helper takes explicit screen offsets. The minimap uses the eighth-scale full-scene image. Mobile prioritises world controls and bottom-sheet stories; its minimap is hidden at narrow widths.
8. Multi-tile object strips calculate depth at the front boundary of the footprint for each screen-x slice. Source shadows are baked; elevated characters have separate baked shadow sprites that stay on the floor. Dynamic hit masks use the actual trimmed alpha bitset. Full-scene LODs share the same baked frames and depth values as live rendering.
9. WebGL is the runtime target. Pixel scale mode is nearest, canvas resolution is one CSS pixel, camera offsets are rounded, and the canvas is styled pixelated. This deliberately uses CSS/world pixels rather than DPR supersampling, keeping the same crisp pixel lattice on retina screens. Physical Android performance has not been measured.
10. Engine input, sprites and camera are framework-independent. React controls the typed Engine API and Zustand owns language, motion, selection and camera UI state. Inspector and Lab are development only; the static review build omits their navigation/routes.
11. Source English, Arabic and Bangla UI dictionaries are bundled to avoid language-switch requests. Font loading is optional and falls back to system fonts; translations await human proofreading. Historical prose and sources remain plainly labelled placeholders.
12. The developer overlay reports actual ticker FPS, visible characters and instrumented WebGL draw calls. Performance targets require a real mobile-device profiling pass before a release claim.
13. Setup uses the existing isolated checkout. Native build scripts are allowed only for sharp and esbuild. `maxrects-packer` is pinned to 2.7.3 because the registry marks 2.7.4 as having broken entry points.

14. Following the screenshot feedback, the initial view is a scene-first 2× close-up with no introduction panel covering the world. The lighter stone palette, adjoining cutaway interiors, 48 additional neighbours, 230 objects, shelves and striped stalls follow the references’ density and layering. All art is still original procedural pixel art. Floor carpets and rugs are baked into background chunks so they cannot occlude characters. `refine-scene.ts` is an explicit art-refresh command; standard startup does not overwrite artist sheets.

15. Vercel’s hosting context is separate from content approval. Importing `main` creates a Vercel Production deployment even while this project is a draft prototype. Therefore `build:vercel` defaults to a clearly labelled prototype on both Preview and Production URLs. The optional `DAR_CONTENT_MODE=approved` selects the strict `pnpm build` release path. All sample approval flags remain false; all denylist, depiction, wardrobe and script validation remains active.

16. Following feedback that characters should be bigger and more visual, and that the world felt too ancient: people now use a 48×72 canvas with the foot anchor at (24,68) (adults about 54 px tall, children about 40 px); cats are 32×24 (16,22), birds 20×20 (10,19). The floor shadow grows to about 16×5 px. Sizes live in `packages/shared/canvas.ts`, shared by the generator, Aseprite importer, compositor and Lab. Every part is drawn from one pose skeleton per action/facing/frame, so any garment fits any adult base; children are the same composite scaled by `CHILD_SCALE` around the foot anchor. Faces stay flat skin with two shade pixels. Seated (`sit`/`write`) poses include a simple stool in the base layer; `read`/`teach` sit on the floor. Explicit SW frames for `pour`/`write` are mirrored copies of SE, kept to exercise the explicit-frame path. Prop sheets omit `pray`, so worshippers carry nothing.
17. The room is now **The Peace Quarter**: a contemporary Muslim neighbourhood (mosque and study circle, architecture studio, science lab, hospital, park, community kitchen, library and coding class, street café, solar garden). The file names `rooms/mosque-garden.tmj`, `content/ambient/mosque-garden.json` and district id `mosque-garden` are kept so URLs, tests and manifests stay stable. Only the back edges of the district carry tall walls; rooms inside are separated by floor materials so tall walls never hide the room in front.
18. Modern draft cards were added for Fazlur Rahman Khan, Zaha Hadid and Aziz Sancar, with only well-known identity facts (name, years, places). Biographies, stories and sources remain placeholders and `panelApproved` is false. Aziz Sancar is living; the panel should confirm consent and depiction policy for living people. Zaha Hadid is shown without a headscarf, matching her public appearance, in a long modest dress; the panel should review. The three historical cards remain, placed beside the modern institutions they inspired. Modern cards use a new `modern-quarter` wardrobe region; historical regions allow only traditional garments.
19. Modern objects use 72 additional palette colours (from `MODERN_COLOURS`), giving saturated accents on light architecture in the manner of the references. Objects flagged `floor: true` (the prayer-hall carpet) are baked into chunks like rugs. The build now loads every `art/tiles/tile-N.png` instead of a fixed six. `refine-scene.ts` was removed; `pnpm gen:placeholder --refresh` replaces it.
20. A football stadium sits east of the ring road, so the room grows from 64×64 to 96×64 tiles (still inside the 4096 px world; the inspector now reads the room size). New actions: `celebrate` (index finger raised), `cheer` (arms wide), `cross-arms`, `kick`, `dive` (goalkeeper), `slide` (tackle), plus `ball_roll`/`ball_still` for a new `ball` kind and base. The ball skips walkability (it may enter the goal) and, having height, gets a separate floor shadow. New bases `adult-man-beard` (full beard) and `adult-man-clean` (clean-shaven); new garments `football-kit`, `football-kit-captain` (armband) and `football-kit-long` (long sleeves). Kits keep the knees covered: shorts to the knee, then long socks. No club crests, sponsors, numbers or brand marks are drawn; colours only suggest a white home kit and a red-and-white kit.
21. Draft cards for Karim Benzema and Mesut Özil (both living) are unapproved with placeholder research, like the others; the panel's living-person policy applies. Özil's famous goal is staged as choreography over the 240-frame master loop (15 s of play, 5 s reset in which the keeper kicks the ball back out). Action frames follow the global clock (frameMap over 60 frames), so step boundaries are chosen to land on the intended frames, such as the strike frame of each kick.
22. Common transliterations of denylisted given names (Mohamed, Mohammed, Mohammad, Muhammed, Mohamad, Ahmed) are now on the denylist themselves, so they block by default exactly like the canonical spelling. `Mohamed Salah` was added to the exact full-name allowlist on the project owner's explicit approval (2026-11); it is not a blanket exception for the name. Players wear their club's kit colours and trims (Real Madrid white, Arsenal red with white sleeves, Liverpool red with white trim); crests, sponsors, numbers and maker marks are deliberately not drawn. New bases `adult-man-curly` (curls with full beard) and `adult-man-goatee` (top-only hair with a bleached stripe and chin beard), garment `football-kit-sleeved`, and actions `arms-out` and `hand-on-heart`.
23. On the project owner's instruction, characters now have simple pixel faces: brows and eyes, plus a two-pixel mouth when no beard hides it. Nothing detailed or realistic. The original rule 6 (featureless faces) is replaced in AGENTS.md and on the About page. Prophets, Ahl al-Bayt, the Prophet's wives, Maryam and the Companions are still never depicted in any form.
24. Clicking a named character opens its card with **Quick facts** (a short summary of well-established facts, labelled unreviewed) and a **Learn more · Wikipedia** link that opens in a new tab. The app never fetches external content; the sandbox could not reach Wikipedia, so summaries were written conservatively and avoid claims that change, such as current clubs. Biographies and stories remain placeholders for panel research. Summaries are English only for now; Arabic and Bangla fall back to English until translated.
25. N’Golo Kanté wears Chelsea's royal blue (new `royal-blue` ramp) on a new close-shaved base, `adult-man-shaved`, and dribbles a 120-frame loop through midfield with the ball at his feet. His card is an unapproved draft with quick facts and a Wikipedia link, like the others.
