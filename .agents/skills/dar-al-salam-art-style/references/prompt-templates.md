# Prompt templates

These templates supplement actual attached references. Always adapt them to
the subject, current user instructions, and image tool requirements.

## Canonical character

Create [subject] in the exact isometric pixel-art rendering style of the supplied
owner reference. Preserve [face, skin tone, hair/beard, costume, accessories].
Match the reference's adult proportions, elevated three-quarter viewpoint,
visible square pixel clusters, stepped edges, and layered dimensional shading.
Use consistent upper-left illumination and cooler shadows. Show the complete
figure, including headwear, hands, and grounded shoes, with generous padding.
No text, calligraphy, logos, or religious symbols. [Specify required background
and transparency using the tool's settings.]

For a turnaround add: show the same model in eight coherent 45-degree rotations
in a regular four-column/two-row grid, at equal scale and elevation. Keep its
identity and asymmetric costume/props consistent when rotated.

## Action sequence

Use the attached canonical model and the owner's style reference. Create exactly
[columns] columns by [rows] rows of equally sized full-body animation cells.
Row [n] depicts [action] in [precise facing]. Show [ordered physical phases]
with small, coherent changes and a smooth return to the initial pose.
Keep body size, costume, facial identity, lighting, viewpoint, and shoe anchor
constant. Include the whole figure in every cell. No unrelated alternate designs.
Background/transparency: [specify]. Do not include labels or decorative borders.

Describe motion concretely. For example: support the book with the left hand,
approach the page edge with the right fingertips, lift one page, rotate it over,
settle it, and return the hand. Avoid vague instructions such as "make it smooth"
without specifying the motion.

## Props and equipment

Create [object] in the same isometric pixel-art material/lighting style as the
character. Use coherent solid geometry with complete opaque interiors and
readable depth. Include every leg, support, handle, and ground contact.
For an animation, keep [fixed parts] pixel-stable and move only [moving parts]
through [small specified motion]. Do not change object design between views.
No text or logos; include ample empty cell padding and the required background.
